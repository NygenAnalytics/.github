| Repository | What it does | Get started |
| :-- | :-- | :-- |
| **[CyteArc](https://github.com/NygenAnalytics/CyteArc)** | Out-of-core single-cell analysis for RNA, ATAC, protein, and multi-omic data. Scales to 100M+ cells, and every result traces back to the cells and parameters behind it. | `pip install cytearc` · [Docs](https://docs.nygen.io/CyteArc/) |
| **[CyteType](https://github.com/NygenAnalytics/CyteType)** | Evidence-backed cell type annotation for Scanpy / AnnData, with a Cell Ontology ID, confidence, and an HTML report for every cluster. | `pip install cytetype` · [Docs](https://www.nygen.io/docs/cytetype) · [Paper](https://www.biorxiv.org/content/10.1101/2025.11.06.686964v1) |
| **[CyteTypeR](https://github.com/NygenAnalytics/CyteTypeR)** | The same annotation workflow for Seurat objects. | `devtools::install_github("NygenAnalytics/CyteTypeR")` |
| **[CyteOnto](https://github.com/NygenAnalytics/CyteOnto)** | Semantic comparison of cell type labels in Cell Ontology space, for benchmarking annotators. | Hosted service. See the repo. |
